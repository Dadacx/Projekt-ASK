Długość słowa: 8 bitów.
Kody rozkazów:

+--------------+---------------+-------------------+-------------+-----------------------+-------------------------------------------------------------------------------+
| Kod rozkazu  | Argumenty     | Bajt 2            | Długość     | Mnemonik              | Opis działania                                                                |
| (Bity 7..4)  | (Bity 3..0)   |                   |             |                       |                                                                               |
+--------------+---------------+-------------------+-------------+-----------------------+-------------------------------------------------------------------------------+
| 0000         | aa bb         | -                 | 1 bajt      | MOV Raa, Rbb          | Przesyłanie danych między rejestrami. Kod 0000 0000 (MOV R0, R0) pełni        |
|              |               |                   |             | (Alias: NOP)          | sprzętowo funkcję NOP.                                                        |
+--------------+---------------+-------------------+-------------+-----------------------+-------------------------------------------------------------------------------+
| 0001         | aa 00         | L7...L0           | 2 bajty     | MOV Raa, nat          | Ładowanie wartości natychmiastowej do rejestru.                               |
+--------------+---------------+-------------------+-------------+-----------------------+-------------------------------------------------------------------------------+
| 0010         | aa s0         | M7...M0           | 2 bajty     | MOV Raa, SEG:[pam]    | Odczyt z pamięci do rejestru. Bit s wybiera segment: 0 = CS, 1 = DS.          |
|              |               |                   |             | (domyślnie DS)        |                                                                               |
+--------------+---------------+-------------------+-------------+-----------------------+-------------------------------------------------------------------------------+
| 0011         | -             | -                 | -           | -                     | Kod nieużywany.                                                               |
+--------------+---------------+-------------------+-------------+-----------------------+-------------------------------------------------------------------------------+
| 0100         | aa bb         | -                 | 1 bajt      | ADD Raa, Rbb          | Dodawanie dwóch rejestrów. Aktualizuje Flagi.                                 |
+--------------+---------------+-------------------+-------------+-----------------------+-------------------------------------------------------------------------------+
| 0101         | aa 00         | L7...L0           | 2 bajty     | ADD Raa, nat          | Dodawanie wartości natychmiastowej. Aktualizuje Flagi.                        |
+--------------+---------------+-------------------+-------------+-----------------------+-------------------------------------------------------------------------------+
| 0110         | aa bb         | -                 | 1 bajt      | SUB Raa, Rbb          | Odejmowanie rejestrów. Aktualizuje Flagi.                                     |
+--------------+---------------+-------------------+-------------+-----------------------+-------------------------------------------------------------------------------+
| 0111         | aa 00         | L7...L0           | 2 bajty     | SUB Raa, nat          | Odejmowanie wartości natychmiastowej. Aktualizuje Flagi.                      |
+--------------+---------------+-------------------+-------------+-----------------------+-------------------------------------------------------------------------------+
| 1000         | aa 00         | L7...L0           | 2 bajty     | CMP Raa, nat          | Porównanie rej-nat. Zmienia Flagi.                                            |
+--------------+---------------+-------------------+-------------+-----------------------+-------------------------------------------------------------------------------+
| 1001         | aa bb         | -                 | 1 bajt      | CMP Raa, Rbb          | Porównanie rej-rej. Zmienia Flagi.                                            |
+--------------+---------------+-------------------+-------------+-----------------------+-------------------------------------------------------------------------------+
| 1010         | aa ff         | L7...L0           | 2 bajty     | AND/OR/XOR Raa, nat   | Funkcje logiczne. Bity ff wybierają operację: 00 = AND, 01 = OR, 10 = XOR.    |
+--------------+---------------+-------------------+-------------+-----------------------+-------------------------------------------------------------------------------+
| 1011         | cc 00         | L7...L0           | 2 bajty     | Jcc [adres]           | Skoki. Bity cc wybierają warunek: 00 = JMP (Bezwarunkowy); 01 = JE (Gdy       |
|              |               |                   |             |                       | Równe); 10 = JG (Gdy Większe); 11 = JL (Gdy Mniejsze).                        |
+--------------+---------------+-------------------+-------------+-----------------------+-------------------------------------------------------------------------------+
| 1100         | aa m0         | L7...L0           | 1 lub 2     | CALL                  | Wywołanie podprogramu. Bit m decyduje o trybie: 0 = CALL Raa (adres w Raa,    |
|              |               | (zależnie od m)   | bajty       |                       | dł. 1 bajt); 1 = CALL [adres] (adres 8-bit, dł. 2 bajty).                     |
+--------------+---------------+-------------------+-------------+-----------------------+-------------------------------------------------------------------------------+
| 1101         | aa p0         | -                 | 1 bajt      | PUSH/POP              | Obsługa stosu. Bit p wybiera tryb: 0 = PUSH Raa; 1 = POP Raa.                 |
+--------------+---------------+-------------------+-------------+-----------------------+-------------------------------------------------------------------------------+
| 1110         | 00 00         | -                 | 1 bajt      | MOVS                  | Operacja łańcuchowa z adresowaniem indeksowym (domyślnie używa R1 jako        |
|              |               |                   |             |                       | indeksu źródła, R2 jako indeksu celu).                                        |
+--------------+---------------+-------------------+-------------+-----------------------+-------------------------------------------------------------------------------+
| 1111         | s0 aa         | -                 | 1 bajt      | MOV Seg, Raa          | Ładowanie segmentu. Bit s wybiera segment: 0 = CS; 1 = DS.                    |
